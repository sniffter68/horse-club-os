# Безопасность и персональные данные

Horse Club OS обрабатывает персональные, медицинские и финансовые данные. Репозиторий должен содержать только программный код и документацию.

Нельзя добавлять в Git:

- дампы базы данных, резервные копии и содержимое `wp-content`;
- `wp-config.php`, `.env`, пароли, токены, ключи API и cookies;
- фотографии, скриншоты и выгрузки с реальными клиентами;
- журналы сервера и отладочные файлы с персональными данными.

Перед каждым коммитом проверяйте список изменённых файлов. Если секрет уже попал в Git, одного удаления файла недостаточно: секрет необходимо немедленно заменить, а историю репозитория очистить отдельно.

Уязвимости и утечки данных не следует описывать в публичных Issue. Передавайте детали владельцу проекта по закрытому каналу.
