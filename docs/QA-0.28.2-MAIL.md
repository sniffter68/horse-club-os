# QA 0.28.2 — восстановление пароля

## Предусловия

- Horse Club OS 0.28.2 активен.
- FluentSMTP подключён к `smtp.yandex.ru` и назначен основным соединением.
- У пользователя указан действующий email.

## Проверка

1. Открыть форму входа Horse Club OS и перейти по ссылке «Забыли пароль?».
2. Запросить восстановление для тестового пользователя.
3. В журнале FluentSMTP убедиться, что письмо с темой «Доступ в Horse Club OS» получило статус `sent`.
4. Проверить, что имя отправителя — «Союз любителей конного спорта».
5. Открыть письмо и убедиться, что кнопка «Задать новый пароль» ведёт на `wp-login.php?action=rp` текущего домена CRM.
6. Задать новый пароль и войти через фирменную форму.

## Ожидаемый результат

- Письмо доставляется на внешний адрес без ошибки `SMTP: данные не приняты`.
- Ссылка открывает штатную защищённую форму WordPress.
- После смены пароля пользователь входит в Horse Club OS со своей прежней ролью.
