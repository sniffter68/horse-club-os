# QA 0.28.7 — параметры услуги и снимки занятия

## Подготовка

1. Открыть существующую активную услугу.
2. Убедиться, что заполнены продолжительность, максимум участников и базовая стоимость.

## Проверка услуги

1. Очистить продолжительность и попробовать сохранить — сохранение должно быть заблокировано.
2. Восстановить продолжительность, очистить вместимость — сохранение должно быть заблокировано.
3. Восстановить вместимость, очистить стоимость — сохранение должно быть заблокировано.
4. Указать стоимость `0` — бесплатная услуга должна успешно сохраниться.

## Проверка занятия

1. Создать занятие и выбрать полностью заполненную услугу.
2. Оставить длительность, вместимость и цену занятия пустыми.
3. Сохранить занятие.
4. Убедиться, что значения скопированы из услуги, время окончания рассчитано, а название сформировано автоматически.
5. Для услуги без допустимых исходных параметров сохранение занятия должно быть заблокировано понятным сообщением.
