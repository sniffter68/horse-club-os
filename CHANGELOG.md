# История версий Horse Club OS

Формат основан на Keep a Changelog. Нумерация версий следует Semantic Versioning.

## [0.28.2] — 2026-08-16

- Имя отправителя системных писем изменено на «Союз любителей конного спорта».
- Стандартное письмо восстановления пароля заменено на брендированный HTML-шаблон Horse Club OS.
- Ссылка смены пароля по-прежнему создаётся штатным защищённым механизмом WordPress.
- Добавлены регрессионные проверки отправителя, темы, ссылки и формата письма.

## [0.28.1] — 2026-08-16

- С панели тренера убрана недоступная быстрая ссылка создания абонемента.
- Поле «Комментарий администратора» занятия скрыто от тренера как служебное.
- Добавлены регрессионные проверки интерфейса и защищённых полей роли тренера.

## [0.28.0] — 2026-08-16

- Добавлена фирменная форма входа Horse Club OS на корне домена CRM.
- Авторизация использует штатные учётные записи, cookies и проверку паролей WordPress.
- Администратор, руководитель и тренер после входа направляются в рабочую панель с доступом согласно роли.
- Прямое открытие стандартной формы входа перенаправляется на фирменный экран; восстановление пароля и повторная авторизация WordPress сохранены.
- Добавлена явная кнопка выхода из панели Horse Club OS.
- Запрещено отмечать присутствие и неявку до фактического начала занятия.
- Добавлена независимая защита отчётов от преждевременно сохранённой посещаемости.
- Добавлен одноразовый версионированный пересчёт оплаты и задолженности для существующих абонементов и разовых записей.
- Список абонементов больше не показывает «Оплачено», если расчётные финансовые поля отсутствуют.
- Добавлены регрессионные проверки входа, прав доступа, посещаемости, статусов оплаты и повторного запуска финансового пересчёта.

## [0.27.0] — 2026-08-16

- Добавлена интеграция с официальным WordPress MCP Adapter через Composer.
- Добавлен слой `HCOS_MCP` поверх WordPress Abilities API.
- Добавлены read-only abilities `hcos/health-check`, `hcos/inspect-booking`, `hcos/inspect-client-relations` и `hcos/inspect-membership`.
- MCP abilities используют существующие права Horse Club OS; финансовые данные доступны только пользователям с `hcos_view_finances`.
- Добавлена безопасная загрузка Composer autoload и включение MCP только при наличии WordPress Abilities API.
- Добавлена поддержка стандартного HTTP MCP endpoint и удалённой аутентификации через WordPress Application Passwords.
- Исправлено чтение представителей клиента через фактическое поле `client_guardians`.
- Release ZIP теперь включает production Composer dependencies.
- Добавлены CI-проверки Composer на PHP 7.4/8.3 и runtime smoke-test MCP на WordPress 7.0.
- Добавлена документация по безопасному удалённому MCP-подключению.

## [0.26.0] — 2026-08-13

- Экран отчётов перенесён в единый интерфейс Horse Club OS.
- Добавлена навигация к отчётам из бокового меню для администратора и руководителя.
- Сохранены проверенные расчёты занятий, посещаемости, выручки, долгов, абонементов и новых клиентов.
- Обновлены таблицы посещаемости, статусов и загрузки тренеров и лошадей.
- Добавлены быстрые переходы к платежам и расписанию и адаптивное отображение.

## [0.25.0] — 2026-08-13

- Добавлен единый рабочий экран записей на занятия в интерфейсе Horse Club OS.
- Добавлены показатели записей, ожидаемых отметок, посещаемости, неявок и задолженности.
- Реализованы поиск по всаднику, плательщику и услуге, выбор периода и фильтры по статусу записи и посещению.
- В таблице объединены занятие, всадник, фактический плательщик, посещение, абонемент или способ оплаты и долг.
- Финансовые сведения скрываются от пользователей без соответствующего права.

## [0.24.0] — 2026-08-13

- Добавлен единый рабочий каталог услуг в интерфейсе Horse Club OS.
- Добавлены показатели общего количества и активных услуг, категорий и занятий на сегодня.
- Реализованы поиск по названию, категории и тренеру и фильтр по статусу.
- В каталоге отображаются формат, вместимость, длительность, цена, возможность оплаты абонементом, ограничения, допустимые тренеры и использование за день.
- Цена скрывается от пользователей без права просмотра финансов.

## [0.23.0] — 2026-08-13

## [0.22.0] — 2026-08-13
