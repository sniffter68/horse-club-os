# Horse Club OS

Рабочая версия административного WordPress-плагина для конного клуба.

## Возможности

- типы записей: Клиенты (`clients`), Лошади (`horses`), Тренеры (`trainers`), Услуги (`services`), Занятия (`lessons`), Записи на занятия (`bookings`), Тарифы (`pricing_plans`), Абонементы (`memberships`), операции абонементов (`membership_ops`) и Платежи (`payments`);
- доступ CPT через стандартный WordPress REST API;
- поля, зарегистрированные программно через ACF PHP API;
- связи занятия с клиентом, лошадью, тренером и услугой;
- дата, время, статус и комментарий занятия;
- колонки телефона, email и статуса в списке клиентов;
- роли клиента (всадник, родитель, плательщик, владелец), связи с представителями и плательщиком;
- предпочтения, источники привлечения, каналы связи и согласия клиентов;
- расширенная карточка лошади: владелец, порода, специализация, уровень всадника, нагрузка и недоступность;
- расширенная карточка тренера: квалификация, услуги, график, нагрузка, ставка и пользователь WordPress;
- расширенная услуга: формат, вместимость, ограничения, правила отмены и возможность оплаты абонементом;
- расширенное занятие: плательщик, продолжительность, время окончания, историческая цена, посещение и причины отмены;
- блокировка пересекающихся занятий по тренеру и лошади с учётом продолжительности и отмен;
- недельное расписание в интерфейсе Horse Club OS с навигацией, статусами, заполненностью и фильтрами по тренеру и лошади;
- отдельная главная панель администратора с расписанием дня, показателями, срочными задачами и быстрыми действиями;
- единый экран клиентов с поиском, фильтрами, контактами, ролями, плательщиком и текущим абонементом;
- отдельные записи участников на занятие с вместимостью, статусом, посещением, плательщиком, абонементом и оплатой;
- безопасный перенос всадников из ранее созданных занятий в `bookings` без удаления старых данных;
- абонементы со всадником, плательщиком, услугами, сроком, объёмом, стоимостью и заморозкой;
- тарифы/пакеты с версией условий; при продаже абонемент получает независимый снимок количества, цены, срока, услуг и правил;
- журнал начислений, списаний, возвратов и корректировок с автоматически рассчитанным остатком;
- в остатке учитываются только опубликованные операции; отклонённые черновики не изменяют баланс;
- журнал денежных платежей и возвратов с плательщиком, способом оплаты и назначением;
- связь платежа с абонементом, записью на занятие или произвольным назначением;
- автоматический расчёт оплаченной суммы и задолженности по абонементам и записям;
- ожидающие, отменённые и черновые платежи не уменьшают задолженность;
- посещение и неявка участника автоматически списывают одно занятие с выбранного абонемента;
- отмена клубом и уважительная отмена автоматически возвращают ранее списанное занятие;
- клиентская отмена учитывает сохранённое окно бесплатной отмены и правило поздней отмены услуги;
- повторное сохранение записи не создаёт дублирующиеся списания или возвраты;
- отдельный экран «Отчёты» для администратора и руководителя с фильтром периода;
- показатели занятий, посещаемости, чистой выручки, долгов, абонементов и клиентов;
- таблицы загрузки тренеров и лошадей по занятиям;
- сохранение данных при деактивации или удалении плагина.

## Требования

- WordPress 6.2 или новее;
- PHP 7.4 или новее;
- активный плагин Advanced Custom Fields (ACF). ACF остаётся обязательной зависимостью.

## Установка ZIP-файлом

1. Установите и активируйте Advanced Custom Fields.
2. В WordPress откройте **Плагины → Добавить новый → Загрузить плагин**.
3. Выберите `horse-club-os.zip`, установите и активируйте его.

## Установка в локальный Docker WordPress

Распакуйте папку `horse-club-os` по адресу:

`C:\horse-club-os\wordpress\wp-content\plugins\horse-club-os`

Итоговый основной файл должен находиться здесь:

`C:\horse-club-os\wordpress\wp-content\plugins\horse-club-os\horse-club-os.php`

Затем активируйте **Horse Club OS** в панели WordPress. Если каталог WordPress подключён в контейнер как volume, перезапуск контейнера обычно не требуется.

## REST API

После активации доступны стандартные маршруты WordPress REST API:

- `/wp-json/wp/v2/clients`
- `/wp-json/wp/v2/horses`
- `/wp-json/wp/v2/trainers`
- `/wp-json/wp/v2/services`
- `/wp-json/wp/v2/lessons`
- `/wp-json/wp/v2/bookings`
- `/wp-json/wp/v2/pricing_plans`
- `/wp-json/wp/v2/memberships`
- `/wp-json/wp/v2/membership_ops`
- `/wp-json/wp/v2/payments`

Чтение и изменение данных требуют пользователя WordPress с подходящими правами. ACF-поля публикуются в REST-ответах при использовании актуальной версии ACF.

## Разработка и GitHub

Папка `horse-club-os` является корнем репозитория. В Git хранятся только код и документация: базы, резервные копии, реальные выгрузки и секреты исключены.

- история версий: `CHANGELOG.md`;
- правила защиты данных: `SECURITY.md`;
- безопасное обновление и откат: `docs/SAFE-UPDATE.md`;
- план пилотной эксплуатации и критерии готовности: `docs/PILOT.md`;
- локальная сборка: `powershell -ExecutionPolicy Bypass -File .\scripts\build-release.ps1 -Version 0.17.0`;
- GitHub Actions проверяет PHP 7.4 и 8.3 при каждом push и pull request;
- тег вида `v0.17.0` запускает проверку и создаёт устанавливаемый ZIP как артефакт Actions.

## Ограничения MVP

В этой версии нет клиентского фронтенда, интеграции с VK, онлайн-эквайринга, фискальных чеков и специализированных бизнес-эндпоинтов. Платежи вносятся администратором или руководителем вручную. Частичное списание занятия и спорные поздние отмены остаются ручным решением администратора. REST API использует штатные контроллеры WordPress.

## Роли и защита данных

- `Администратор` сохраняет полный доступ к WordPress и Horse Club OS;
- `Руководитель Horse Club OS` управляет всеми сущностями CRM, финансами, чувствительными заметками и журналом изменений;
- `Тренер Horse Club OS` работает с клиентами, лошадьми, тренерами, услугами, занятиями и записями, но не видит платежи, абонементы, цены, долги, медицинские и внутренние заметки и не может удалять записи;
- те же ограничения применяются к ACF-полям в REST API;
- критичные изменения статусов и ACF-полей сохраняются в `Инструменты → Журнал изменений`;
- медицинские, внутренние и финансовые значения в журнале заменяются отметкой `[скрыто]`.

После обновления роли создаются автоматически. Назначить их можно в `Пользователи → Все пользователи`.

## Отчёты руководителю

Экран `Отчёты` доступен администратору и роли `Руководитель Horse Club OS`. По умолчанию показывается текущий месяц, период можно изменить. Выручка считается по опубликованным платежам со статусом «Оплачен» за вычетом возвратов. Текущие долги и остатки занятий показываются на момент открытия отчёта, независимо от выбранного периода.

## Резервные копии

Плагин не складывает копии персональных данных в публичный каталог `uploads`. Полная резервная копия должна включать базу данных WordPress и каталог `wp-content`. Для локального Docker копируйте базу и проект вне контейнера и обязательно проверяйте восстановление в отдельном тестовом контейнере. Краткая памятка доступна в `Инструменты → Безопасность Horse Club OS`.
